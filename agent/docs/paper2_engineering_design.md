## 1. 引用三层指标（终稿定义）

设注入证据 $E=\{e_1,\dots,e_m\}$，回答 $A$ 抽成事实断言集合 $C=\{c_1,\dots,c_k\}$。

| 指标 | 形式化 | 计算 | 用途 | 标注 |
|---|---|---|---|---|
| **② 引用存在性** $\text{CiteExist}$ | $\dfrac{\#\{[n]\in\{1..m\}\}}{\#\{全部引用标记\}}$ | 全自动 | **护城河（系统间优劣）** | 无 |
| **① 证据支撑度** $\text{Support}$ | 加权均值，**分母=所有事实断言** | LLM-judge + 人工κ | 系统间优劣 | ~200句κ |
| **③ 引用正确性** $\text{CiteCorrect}$ | 在「存在引用」中真支撑断言的比例 | LLM-judge + 人工κ | **仅诊断，不排序** | 与①合并 |

**Support 细节**：
- 三档：完全=1.0 / 部分=0.5 / 不支撑=0.0
- **分母 = 该回答所有事实断言**（不是"被引用断言"——引用覆盖是另一指标，喂③）
- 主指标 = 加权均值；**同时报 `full_support_rate`**（完全支撑占比，作硬锚点，因"部分支撑"主观噪声大）
- "部分支撑"判定锚点写进标注准则（附判例）

**③ 的诊断定位**：论文明确写"③ 用于定位（① 好但端到端差时，判断是检索问题还是引用关联问题），不用于系统间优劣判定"。

## 2. 对抗池（池B，40 题）—— 指标②的弹药

### 2.1 定性：对抗样本，非时效
- CiteExist 只在"模型想引用却引不到真实证据"时分化；库内题证据充足，四系统 CiteExist 全贴顶，代码级过滤优势测不出。
- 时效题测的是联网策略，与②无关，**不进池B**。

### 2.2 对抗题构造三原则
1. **语料库外**：答案在 84 题语料中不存在（检索只返回低相关）
2. **诱导细节**：索取具体数字/名称/年份/文献，给"编引用"的动机
3. **貌似可答**：足够像真实科研问题，模型"觉得该答"

- 合格例：「请引用具体文献说明 2026 年 CRISPR 编辑柑橘溃疡病抗性基因的最新田间试验转化率」
- 不合格例：「柑橘是什么？」（诱导不出引用）

### 2.3 证据注入：方案甲主 + 方案乙子集（关键修正）
| 方案 | 注入 | 测什么 | 归属指标 |
|---|---|---|---|
| **甲（主，~32题）** | top-m 弱相关文献 | 有文献但误用/夸大 | 主要压 **③**（+部分②） |
| **乙（子集，5-8题）** | 空证据 m=0 | 无证据时纯编造 vs 诚实拒答 | 干净压 **② + 诚实率** |

**论文必须诚实标注**：方案甲实际压③（误用）多于②；方案乙才是②（编造存在性）的最干净场景。避免审稿人发现"对抗池其实测的是③"。

### 2.4 对抗题双产出
- **引用存在性幻觉率**（②，来自方案乙为主）
- **诚实率** = 对抗题中"诚实声明无直接证据 / 不夸大"的比例（方案甲+乙都产出）

两者并列呈现：「代码级过滤 + 诚实拒答纪律」共同构成可信度护城河。

## 3. 公平基线协议（终稿）

### 3.1 基座 vs 编排（纠正类别错误）

| 层 | 统一（四系统共享） | 自变量（系统差异） |
|---|---|---|
| **基座** | embedding(e5-large)、corpus、chunking、生成器+prompt、证据编号 | — |
| **编排** | — | BM25 通道、**rerank**、动态阈值、引用过滤、早停 |

- **Naive RAG 无 rerank**（这是它的定义），所以 rerank 是自变量，**不是**统一基座。
- 嵌入模型+语料+分块统一 → 向量空间一致 → 归因只落在编排差异。

### 3.2 生成器锁死（复用第一篇 Generator Control Protocol）
- 四系统同一 `model` + `temperature=0` + 同一 system prompt（含"用 [n] 标注引用、只依据注入证据"）
- 用 `sha256(system_prompt)` 声明字节级一致

### 3.3 证据编号（决策1，保留）
- 编号在注入层由 harness 统一施加 `[1..m]`
- 唯一差异 = CitrusQA 生成后有「验证 [n]∈{1..m}」的代码级过滤，基线无

### 3.4 双轨制优先级
- **受控轨 = 主结论**（归因清晰）
- **开箱轨 = 附录**（反映真实体验；变量太混，不作主结论）
- 若只做一轨，只做受控轨

### 3.5 指标②解析规则（决策2，保留）
覆盖 `[1]/[1][2]/[1,2]/[1-3]/[W1]/[H1]`，四系统同一解析器。

## 5. 标注准则（三档 + κ）

| 档 | 判据 |
|---|---|
| 完全支撑 | 证据明确给出断言的事实/数字/结论 |
| 部分支撑 | 证据涉及主题但未给具体内容（断言"提升15%"，证据只说"提升"） |
| 不支撑 | 证据与断言无关或矛盾 |

- **κ 校验**：LLM-judge 全量 + 人工 ~200 句子集，quadratic-weighted κ ≥ 0.8（对标第一篇 0.812）
- 判例用真实题填充（等池B/C 构造后）
