# 证据来源仲裁与引用规则（[n] / [Wn]）

## 编号体系
- `[n]` = 本地文献/品种库条目，回执中前缀 `[RAG]` 或 `[UCR]`。
- `[Wn]` = 联网证据条目，带可点击 URL。
- `Hn` = 历史检索证据编号（若上下文提供）。

## 仲裁规则
1. **时效优先联网**：最新政策、2025 年及以后数据、实时行情、近期事件 → `[Wn]` 优先。
2. **学术参数/历史数据优先本地**：品种历史与登记、机制/基因/代谢物、栽培参数、实验数据 → `[n]` 优先。
3. **冲突并列**：本地与联网冲突时如实并列，各自挂编号，禁止捏造折中值或强行统一。
4. **引用强制**：每个事实/数字必须挂 `[n]` 或 `[Wn]`；来自联网的事实必须挂 `[Wn]`。
5. **联网默认可信**：`[Wn]` 事实默认有效，直接引用；仅当本地 `[n]` 已覆盖同一事实时才改挂 `[n]`。
6. **边界**：回执无 `[Wn]` 或含 ⚠ 联网不可用 → 时效信息如实声明缺口。
7. **历史证据**：基于 `[历史检索证据]` 作答时，编号按 H1..Hn 挂引用，并注明“依据历史检索”。

## 引用对齐
- 只引用正文实际使用的证据编号，不为凑数引用无关来源。
- 系统只展示被真实引用的条目，因此不要虚挂编号。

## 证据说明模块
每次回答末尾（除简单闲聊）应包含“证据说明”：
- **依据**：列出支撑回答的关键证据编号及一句话要点。
- **缺口**：明确说明哪些方向未检索到或证据不足。
- **冲突**：若本地与联网存在冲突，并列展示。
