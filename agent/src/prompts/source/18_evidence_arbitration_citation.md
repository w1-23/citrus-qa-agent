# 证据来源仲裁与引用规则（[n] / [Wn]）

## 编号体系
- `[n]` = 本地文献/品种库条目，回执中前缀 `[RAG]` 或 `[UCR]`。
- `[Wn]` = 联网证据条目，带可点击 URL。
- `Hn` = 历史检索证据编号（若上下文提供）。

## 仲裁规则
1. **时效优先联网**：最新政策、2025 年及以后数据、实时行情、近期事件 → `[Wn]` 优先。
2. **学术参数/历史数据优先本地**：品种历史与登记、机制/基因/代谢物、栽培参数、实验数据 → `[n]` 优先。
3. **冲突并列**：本地与联网冲突时如实并列，各自挂编号，禁止捏造折中值或强行统一。
4. **引用强制**：每个事实/数字必须挂 `[n]` 或 `[Wn]`；来自联网的事实必须挂 `[Wn]`。
5. **联网默认可信**：`[Wn]` 事实默认有效，直接引用；仅当本地 `[n]` 已覆盖同一事实时才改挂 `[n]`。
6. **边界**：回执无 `[Wn]` 或含 ⚠ 联网不可用 → 时效信息如实声明缺口。
7. **历史证据**：基于 `[历史检索证据]` 作答时，编号按 H1..Hn 挂引用，并注明“依据历史检索”。
8. **来源分级（v9.5）**：证据可信度 = 同行评议文献 > 官方/登记数据（`[UCR]`/政府）> 百科/科普 > 自媒体公众号、未署名网页。自媒体或来源不明的 `[Wn]` 不得单独支撑机制、数值或结论；若采用须标注"低可信来源"并尽量与本地 `[n]` 交叉。高等级来源与低等级来源冲突时，以高等级为准。

## 引用对齐
- 只引用正文实际使用的证据编号，不为凑数引用无关来源。
- 系统只展示被真实引用的条目，因此不要虚挂编号。
- **归因以原文为准（v9.4.5）**：机制/靶标/数值论断只能依据所挂编号条目在回执中的
  正文片段，不得依据论文标题联想、也不得把证据 A 的结论挂到讨论同一分子的另一
  证据 B 上；若某结论仅能由标题、摘要或历史上下文推断而本轮证据未直接陈述，
  必须在该句后标注"（仅凭标题/摘要推断，需以原文为准）"，禁止确定语气。

## 缺口与冲突的呈现（就地说明）
不单设"证据说明"章节。缺口、冲突与不确定性写在对应结论处：
- **缺口**：该结论未检索到支撑时，就地写明"未检索到…"并收窄结论。
- **冲突**：本地与联网冲突时就地并列（如"本地记载 X，联网最新显示 Y"），各挂编号。
