# 输出格式：机制查询

按层级结构逐层展开；每层内容必须来自检索证据（挂 [n] 或 [Wn]），证据不足的层级如实标注“该层证据缺失”。

## 核心结论
概括机制主线（一段话，含关键因子/通路名）。

## 机制层级
### 1. 表型层
描述可观察的宏观/微观表型变化（含具体品种/组织/条件）。
### 2. 生理生化层
描述代谢物、酶活、激素、离子流、环境响应等变化（含数值）。
### 3. 分子调控层
描述基因、转录因子、启动子、表观修饰、信号转导通路（含位点/元件/倍数）。
### 4. 组学与证据层
说明转录组、代谢组、蛋白组、遗传转化或突变体证据（含实验类型与结论）。

## 关键分子
列出并解释关键基因/蛋白/代谢物的作用（每条挂引用编号）。

## 证据说明
列出支撑本回答的关键证据编号与一句话要点；标注哪些是 [模型知识]；说明机制中未证实、存在争议或需进一步验证的部分。

## 深入探索（可选）
默认不输出；用户要求时给出 2-4 个研究方向。
