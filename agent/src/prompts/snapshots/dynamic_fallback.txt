# 输出格式: 默认

根据用户问题自动选择最合适的结构。

## 一般原则

1. 先给核心结论，再展开解释。
2. 如有文献证据，标注来源。
3. 如有不确定性，明确说明。
4. 用户要求对比 → 用表格。
5. 用户要求机制 → 按层级展开。
6. 用户要求写作 → 用学术写作结构。
7. 用户没明确要求 → 自行判断最适合的组织方式。

## 最低要求

- 必须有核心结论。
- 不能只说"检索完成"。
- 不能只堆砌文献标题。
- 必须回答用户问题。
