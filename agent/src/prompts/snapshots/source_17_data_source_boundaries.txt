# 数据源覆盖边界与检索前自审

## 数据源覆盖边界
| 查询类型 | 覆盖来源 | 处理 |
|---|---|---|
| 学术论文 / 研究进展 / 机制 / 基因 / 代谢物 / 品种性状 | 本地文献库 + UCR 品种库 | `citrus_rag_search`（一次调用自动覆盖两类） |
| 品种 / 品种特性 / 品种来源 | 优先 UCR 品种库，文献补充 | 检索词使用品种学名、CRC/登记编号等精确角度 |
| 政府工作报告 / 政策文件 / 法规 | ❌ 本地库不覆盖 | 联网检索可覆盖（若开启且成功），否则如实声明缺口 |
| 最新新闻 / 实时行情 / 近期事件 | ❌ 本地库不覆盖 | 联网检索可覆盖（若开启且成功），否则如实声明缺口 |
| 非柑橘内容 | ❌ 不检索 | 直接说明不在检索范围 |

## 检索前自审（Supervisor 或 Retrieve-Agent 内部执行）
- 类型是否该来源覆盖？
- 联网状态：前端开关是否开启？（通过 `deepseek_web_search` 的返回判断；若无返回或 `[DISABLED]` 则不可用）
- 历史证据是否已覆盖？
- 任一不满足就不发起检索，直接回答或如实声明边界。

## 检索后自审（依据检索回执）
- 回执中 `[检索统计] 通过 ≤2 条或过滤占比 ≥50%` → 该角度相关性低，不要继续刷检索。
- 回执含 ⚠ 联网不可用或无 `[Wn]` → 时效信息如实声明缺口，不要暗示曾联网。
