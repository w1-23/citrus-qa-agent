2. 列出风险因素：概述多因素病因，强调幽门螺杆菌感染是主要原因
3. 引用已有证据：指出水果消费降低胃癌风险的已知关联
4. 提出保护机制假设：解释水果中营养素和抗氧化物的保护作用
5. 深化证据链：引用研究报告多酚的抗氧化和化学预防特性
