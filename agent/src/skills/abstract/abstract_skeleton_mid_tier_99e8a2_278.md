## 逻辑骨架 (Rhetorical Moves)

1. 确立研究范围：明确指出本研究探究的是补充LED光谱和强度对柑橘嫁接苗冬季生长的影响
2. 陈述研究目标：说明主要目的是确定不同红蓝白远红LED光组合及强度对短日照下柑橘萌发和接穗生长的影响
3. 描述实验材料与方法：详述所用砧木、接穗品种、生长环境、光周期、实验设计类型及测量指标
4. 报告主要结果：表明补充LED光的质量和强度显著影响所有响应变量，并具体说明不同光谱与强度对萌发和生长的不同影响
