## 逻辑骨架 (Rhetorical Moves)

1. 确立背景：说明柑橘栽培中监测叶片相对含水量（RWC）对水分管理、果实品质和产量的重要性
2. 指出问题：指出应用高光谱技术监测RWC时存在数据噪声、算法适应性、光谱混叠以及叶绿素（LCC）干扰等问题，导致反演精度下降
3. 提出目标与方法：为探索最优预测模型，本研究基于401-2400nm光谱数据，通过连续小波变换（CWT）多尺度分解提取噪声鲁棒特征，建立高精度估计模型，并系统评估CWT的潜力
4. 描述具体步骤：利用CWT的多尺度分析探测RWC和LCC的时频特征模式，采用皮尔逊相关分析评估特征有效性，使用连续投影算法（SPA）提取最优敏感波段组合
5. 展示结果：基于所选敏感波段，利用偏最小二乘回归（PLSR）建立模型，结果表明CWT预处理显著提高了RWC和LCC的估计精度（最大提升6%和3%）
