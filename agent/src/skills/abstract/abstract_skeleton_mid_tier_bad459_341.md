## 逻辑骨架 (Rhetorical Moves)

1. 确立背景共识：说明植物相关微生物在植物营养、健康和适应干旱胁迫中的重要作用
2. 指出决定因素：强调微生物种群选择受土壤理化参数和植物根际效应的影响
3. 引入研究目标：介绍本研究旨在调查突尼斯柑橘相关微生物群落结构和PGP潜力
4. 汇报初步发现：指出细菌群落结构与土壤理化参数相关，并识别了关键驱动因素（钾、碳、有机质）
5. 说明评估方法：通过系统发育和功能表征评估选定菌株作为干旱胁迫下生物肥料和生物刺激剂的潜力
6. 描述实验设计：说明体外筛选、体内测试以及实验组（接种细菌的干旱胁迫植物）和对照组（未接种和充分灌溉）的设置
