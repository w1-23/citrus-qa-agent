## 逻辑骨架 (Rhetorical Moves)

1. 引用前人研究，确立现有共识（感染率与果实大小关系、幼嫩组织抗性）
2. 提出本研究的新发现（更具体的入侵时间点）
3. 指出与前人报告的矛盾（花后10天出现病斑，表明入侵更早）
4. 描述新发现的病变过程细节（早期病变扩大与木质化，不同条件下的时间差异）
5. 通过人工接种实验验证并确认更早的入侵时间窗口
6. 提出潜在解释（全球变暖改变季节适宜性）
7. 基于结果给出实践建议（防治从花期开始并延长至果实成熟）
