1. 总结研究方法和核心发现：描述使用风味组学策略调查不同砧木橙汁的感官属性与代谢物关系，并列出CCA揭示的关键糖类和氨基酸对甜味和风味的贡献
2. 突出主要结果的意义：指出砧木CH能够增强特定氨基酸、糖类和萜类化合物的积累，从而提升感官品质
3. 补充讨论复杂性因素：强调低浓度挥发性化合物的协同效应不可忽视
4. 形成总体结论：总结不同砧木对橙汁风味品质的影响是一个复杂现象，高度依赖于砧木与接穗的互作
5. 指出研究价值：说明研究数据有助于了解砧木选择对HLB抗性或耐受性的重要性
6. 指出研究局限性：承认当前研究仅关注常见风味化合物，全面代谢物谱仍未知，尤其涉及HLB的特定代谢物
7. 提出未来研究方向：声明后续将采用非靶向代谢组学检测更多代谢物，以探索不同砧木对果实品质和植物防御的影响
