## 逻辑骨架 (Rhetorical Moves)

1. 确立研究步骤：说明研究的第一步是植物化学研究

3. 描述方法流程：详细说明从粗提物到活性成分鉴定的步骤
4. 指出研究空白：通过对比指出本研究中两个提取物（n-hexane和DCM）此前未被研究
