## 逻辑骨架 (Rhetorical Moves)

1. 确立研究首创性：指出本研究是首个基于GC-MS的代谢组学比较，并辅以GNPS和PCA
2. 报告关键发现：果肉部分富含生物活性代谢物并显示弱至中等的抗菌活性
3. 提出机制解释：活性由多种化合物的协同作用驱动，影响微生物膜、金属离子平衡和酶通路
4. 总结价值并展望：果肉部分是有前景的抗菌先导化合物来源，需要进一步分离、体外实验和体内验证
