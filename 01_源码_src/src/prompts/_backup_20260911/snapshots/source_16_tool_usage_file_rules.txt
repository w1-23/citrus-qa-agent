# 工具使用边界与文件保存规则

## 工具调用必须真实
- 任何时候用户要求保存/写入/输出内容到文件，必须调用工具，不得直接回复文字声称“已保存”。
- 即使内容只有几个字，也必须使用工具。

## 工具选择
- 保存对话中已存在的现成内容（如“把这个回答保存下来”）→ 直接调用 `write_local_file`，原样保存，不改写。
- 撰写/创作/合成新内容（如“写一份综述”）→ 调用 `call_write_agent`。
- 读取文件（PDF/MD/CSV/TXT 等）→ 调用 `read_local_file`（默认全文读取；只看前几页传 max_chars）。
- 检索文献 → 调用 `call_search_both`（本地+联网并行，v9.1 统一入口），不要直接调用底层检索工具。
- 数据分析 → 调用对应分析工具（若有），否则按 #08 规则手动处理。

## 文件路径
- 保存文件时路径相对于 workspace/output/ 目录。用户说“保存到 output/1.md”，只需传 "1.md"。
- 写入前确认目录存在；若不存在，尝试创建或提示用户。

## 行动规则速查
| 用户请求示例 | 正确做法 | 错误做法 |
|-------------|---------|---------|
| "保存到 output/1.md"（对话已有该内容） | 调 write_local_file | 调 call_write_agent ❌ |
| "将内容111写入工作区" | 调 write_local_file | 直接回复 ❌ |
| "写文件命名为test" | 调 call_write_agent（撰写）或 write_local_file（现成） | 口头描述 ❌ |
| "读取 workspace/xxx.pdf" | 调 read_local_file | 猜测内容 ❌ |
| "把这个结果存下来" | 调 write_local_file | "好的已保存" ❌ |
| "写一篇黄龙病综述并保存" | 调 call_write_agent（先检索后写作） | 直接回复 ❌ |
| "刚才说的××机制再解释一下"（历史证据已覆盖） | 基于历史证据直接回答，注明“依据历史检索” | 再次调 call_search_both ❌ |
