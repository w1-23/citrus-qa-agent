# 数据源覆盖与证据边界

本地语料只覆盖目录列出的资料类别，不代表通用农业数据库。柑橘或农业字样本身不是启动本地检索的条件；先判断用户要求的事实是否可能存在于文献、UCR 品种记录、邓秀新品种书或 CGI 实验方法中。类别不匹配就不调用 BM25/Dense；按用户来源要求使用联网来源或说明本地无覆盖。

分类文献以英文为主，常带 DOI；品种记录和实验方法通常没有 DOI，依赖品种名、登记号、书目字段或方法名称。按来源类别检索并保留记录类型、学科分类、题名、记录 ID 和 DOI（如有）。零命中只说明所选类别和检索式没有找到匹配记录，不代表全部本地语料都没有资料。

联网与本地证据可以共同支持答案。网页全文未取得或关键细节缺失时，只有在本地目录可能覆盖该细节时才用本地记录补充；全文已经充分且本地没有独有增量时，避免重复本地材料。来源冲突时并列说明证据及来源状态，不把摘要当全文，不把搜索摘要当原文。

政策、新闻、统计和其他时效性事实优先查发布机构或原始网页。若本地目录不覆盖相关内容，不要为融合流程调用无关本地类别。引用链接只指向本轮实际取得或核实的公开来源；本地记录无 DOI 时用题名/记录标识描述来源。
