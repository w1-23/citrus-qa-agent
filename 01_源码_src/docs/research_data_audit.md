# CitrusQA 原始数据审查能力

## 使用方式

用户明确要求检查数据、论文源表或统计异常时，主模型先用 `inspect_uploaded_table` 查看复杂表头和样例，再调用统一的 `audit_uploaded_data`。仅上传文件不会自动触发审查。普通表格理解、问答不会执行数值审查。

支持 CSV、TSV、XLSX、XLS、XLSM、XLSB，以及 PDF 和 DOCX 中可提取的结构化表格。一次请求可选择多个文件和多个工作表。原附件只在本次请求的隔离临时目录中处理；临时输入扫描结束即清理。可下载的报告绑定会话，沿用现有文件过期清理机制。

## 检测范围

统一审查调用 PaperConan 0.9.0 的数值检测引擎，并附加 CitrusQA 的通用表格质量检查。

- **列关系**：相同列、固定偏移、固定比例、精确线性关系、和为常数、差值集合、局部偏移/比例、共享小数尾或疑似复制后改数。
- **行关系**：相同/成比例行、局部行复用、行间数字耦合，以及跨块、跨工作表的行复用。
- **单列与整块模式**：等差序列、异常重复、分散重复、舍入网格、舍入后相同、末位缺失/偏好、小数尾聚集、整块分散重复值。
- **跨表关系**：同位置重复、重排后的值重叠、错位小数尾复用、重复列、矩阵/行向量复用。
- **摘要统计**：在适用的整数计数/评分数据上检查 GRIM 均值与 GRIMMER 均值和 SD 一致性。语义不明时不应启用整数数据专属检查。
- **通用质量检查**：缺失、类型混杂、完全重复行、常量字段、探索性 IQR 离群、组别样本数和重复编号数不平衡。

不同模式有样本量、精度、布局及计算预算门槛；不是每条规则对每个表格都适用。上传解析失败、引擎预算触顶、命中被上限截断等情况会随 `scan_status` 和覆盖信息报告，部分扫描不得表述为“未发现问题”。

## 输出与边界

默认生成 XLSX 汇总、HTML 详细报告和 JSON 扫描结果。报告定位为**统计线索**，显示文件、工作表、区块、规则和可用证据。规则信号、离群值和组别不平衡均需结合实验设计、图注、Methods、单位、公式、共享对照和原始记录复核。系统不会改写上传文件，不执行模型生成的代码，不推断作者意图。

本集成本次不启用 PaperConan 图像资产或图像提示检查；空的数值报告也不能说明图像已检查。XLS/XLSB 读取需要 `python-calamine`；PDF/DOCX 表格提取分别需要 `pdfplumber` 和 `python-docx`。依赖清单见 `src/research/vendor/paperconan-requirements.txt`。依赖缺失或格式不可读时，应报告未完成而不是按“无信号”处理。
