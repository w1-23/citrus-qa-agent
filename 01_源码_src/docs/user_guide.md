# CitrusQA 用户指南

## 能做什么

- 回答柑橘科研和一般知识问题；按问题需要使用 Web Search、Web Fetch 或本地柑橘语料检索。
- 理解本轮上传的图片、PDF、Word 和表格。病害图片由当前主模型直接观察；照片判断属于筛查意见，不替代实验室检测。
- 用户明确提出数据审查时，扫描表格和可提取的文档表格，生成一份按类别整理的 HTML 异常报告。单独上传表格不会触发数据审查。
- 解读论文、核验参考文献、准备实验设计或整理课题记录；需要时可导出文件。
- 开启输入区“可视化”，允许回答包含可编辑的 SVG 图示。

## 怎么提问

把目标、材料和希望的结果说清楚即可，例如：

- “比较近五年柑橘黄龙病早期诊断的研究证据，并给我来源链接。”
- “请解释附件论文的研究问题、材料、处理和统计方法。”
- “检查这份实验数据的重复值、异常值和组别平衡，给出一份简明 HTML 报告。”
- “根据这张叶片照片给出最可能的病害和简短筛查建议。”
- “画一张花芽分化实验流程图，并把 SVG 放进回答。”

添加附件后，继续在问题里说明要模型做什么。普通附件理解不会自动转成数据审查。复杂表格的字段名称或表头不清楚时，模型可能先询问字段含义。

## 账号、头像与文件

注册时可选 20 个柑橘头像之一，也可上传 JPG、PNG 或 WebP 图片（不超过 5 MB）；登录后可在左下角账户菜单中更换头像。首次登录会显示一次使用指南，也可从该菜单再次打开。

会话、上传附件和生成文件按账号隔离。附件仅用于当前请求，不会自动加入共享语料。对话和附件内容可能发送给管理员配置的模型与联网服务；不要上传不适合发送给这些服务的敏感材料。
