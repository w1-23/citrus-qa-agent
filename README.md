# CitrusQA｜柑橘科研辅助智能体

CitrusQA 是面向柑橘科研与农业研究的通用 Web Agent。系统围绕科研工作流组织能力：理解问题与附件，按需调用检索、审查和导出工具，再把结果整理为可复核的回答或文件。生产链路采用**一个主 Agent + 按请求裁剪的工具集**；主 Agent 负责任务理解和工具选择，代码落实来源范围、权限、并发和文件边界。

> 病害分类器目前停用。病害图片由具备视觉输入能力的主模型直接查看；照片判断用于初筛，不是确诊。

## 系统流程

~~~mermaid
flowchart TD
    U[用户问题与附件<br/>文字 / 图片 / PDF / Word / 表格] --> AUTH[登录与账号权限]
    AUTH --> CTX[本轮上下文<br/>会话历史 / 摘要 / 账号记忆 / 附件]
    CTX --> ROUTE[判断任务类型与来源范围]
    ROUTE --> ALLOW[建立本轮工具白名单]
    ALLOW --> AGENT[主 Agent 决定直接回答或调用工具]
    AGENT --> LOOP{证据足够？}
    LOOP -- 否 --> TOOL{任务工具}
    TOOL --> WEB[Web Search：发现来源]
    TOOL --> FETCH[Web Fetch / 论文 Fetch：读取页面或尝试公开全文]
    TOOL --> RAG[本地混合检索：BM25 + Dense → RRF → 重排 → 阈值筛选]
    TOOL --> REF[参考文献核验：Web Search + Crossref / DataCite]
    TOOL --> AUDIT[论文与数据审查：PaperConan + 数据质量规则]
    TOOL --> SCI[论文解读 / 实验设计 / 课题记录 / 文件导出]
    TOOL --> SVG[可选 SVG 绘图与安全校验]
    WEB --> BACK[结果状态回到主 Agent]
    FETCH --> BACK
    RAG --> BACK
    REF --> BACK
    AUDIT --> BACK
    SCI --> BACK
    SVG --> BACK
    BACK --> LOOP
    LOOP -- 是 / 达到请求边界 --> OUT[简洁回答 + 按需产物]
    OUT --> SAVE[会话、工具状态与审计摘要<br/>账号隔离保存]
~~~

普通问答不强制检索。用户明确要求文献检索、引用核验、数据审查等任务时开放相关工具；只上传文件不会自动启动数据审查。主 Agent 可根据工具结果继续下一步，代码限制工具循环、请求时长和可访问能力。

## 科研问答与证据检索

- **Web Search**：发现公开网页与文献来源，适合最新进展和外部证据。
- **Web Fetch**：读取指定 URL 或搜索结果的页面正文；摘要不足以支撑关键细节时再调用。
- **论文 Fetch**：根据 DOI、PMID、标题或候选 URL 尝试访问公开全文或开放获取页面；说明真实访问状态，不绕过付费墙。
- **本地混合检索**：查询已安装的柑橘语料。BM25 与 Dense 并行召回，RRF 合并后重排，并按相邻分数衰减阈值过滤候选。送入 BM25/Dense 的本地查询必须是英文；中文问题先翻译，翻译失败或结果仍含中文时停止，绝不回退发送中文。
- **融合检索**：联网证据优先；本地语料只在类别匹配且能补充证据时采用。用户明确指定“仅本地”或“仅联网”时遵守来源限制。
- **参考文献核验**：通过 Web Search 配合 Crossref/DataCite 登记元数据，比较 DOI、题名、作者、期刊和年份。登记库未查到不代表文献不存在；联网失败表示未完成核验。
- **公开补充材料**：仅在用户明确要求时按 DOI 查找并审查可解析文件；未找到归档、网络失败、解析未完成分别报告。

## 多模态附件与视觉问答

支持图片、PDF、Word 和表格附件。文件仅用于当前任务，不自动加入共享语料或长期记忆。图片由所选主模型查看；模型不支持图像输入时会明确说明。柑橘病害图片由多模态主模型给出最可能判断、把握程度和必要筛查建议，不作确诊，不根据单张照片给农药用量。PDF/Word 的文本和表格抽取依赖文件结构；抽取不完整时按未完成处理。

## 论文与原始数据审查

用户需要明确要求审查；单纯上传附件不会触发。

- 支持 CSV、TSV、XLSX、XLS、XLSM、XLSB，以及 PDF/Word 中可提取的结构化表格。
- PaperConan 数值关系检测与通用数据质量检查覆盖重复/复用、异常值、行列与局部数值关系、小数尾/末位模式、缺失和格式、组别与重复结构，以及适用条件下的整数均值/标准差自洽性。
- 结果是可复核的统计线索，不推断作者意图；尽可能标注文件、工作表、行列/区块和触发规则。
- 每次数据审查只生成**一份自动命名的 HTML 异常报告**。报告按类别逐行列出发现；无发现写“无”，未完成项目列出原因。覆盖不完整时不能把未检查写成“无异常”。原件不修改，不运行模型生成的代码。
- PaperConan 的 MIT 许可和来源记录见 01_源码_src/src/research/PAPERCONAN_ATTRIBUTION.md。

## 科研辅助与导出

- **论文解读**：整理研究问题、材料、方法、结果和统计信息。
- **实验设计**：整理处理组、对照、重复、采样点、测定指标及潜在混杂因素；建议不冒充已验证结论。
- **课题记录**：仅按用户明确要求保存或回顾；按账号和课题名隔离，同一账号可跨会话使用。
- **文献证据**：按需导出 XLSX、RIS 或 BibTeX；缺失的书目字段不会补造。
- **其他产物**：论文解读、实验方案、课题记录和语料缺口可按请求导出适用格式。

## SVG 可视化

用户可以开启“可视化”开关。只有图示有帮助时，主 Agent 才生成流程图或结构图；服务端校验 SVG 标签、属性和复杂度后返回可编辑 SVG。开关关闭时，本轮不提供绘图工具。

## 账号、隐私与管理

- 用户名和密码注册登录，密码哈希保存；管理员账号通过私下初始化，不由公开注册流程自动授予。
- 会话、上传任务、生成文件和课题记录按账号隔离；普通用户不能访问管理员页面和管理接口。
- 自动偏好/事实记忆与用户手动保存的课题记录分开管理。
- 管理后台用于账号、队列、请求审计摘要、用量和模型服务配置；模型密钥不展示给普通账号。
- 工具状态区分完成、部分完成、无结果、失败和未执行，并尽可能给出原因、覆盖范围与产物入口。对话及附件可能发送给已配置的模型或联网服务，请勿上传不适合外传的敏感材料。

## 任务与工具路由

| 用户任务 | 工具能力 | 典型输出 |
| --- | --- | --- |
| 普通问答、问候 | 主 Agent | 直接回答 |
| 找文献、查进展、外部证据 | Web Search；必要时 Web Fetch/论文 Fetch；主题匹配时本地检索 | 带来源的回答 |
| 仅本地 / 仅联网 / 融合检索 | 与来源要求一致的工具子集 | 标明来源及未命中状态 |
| 核验 DOI、题名、参考文献 | Web Search、元数据核验 | 匹配/不一致/未查到/未完成 |
| 获取 DOI 对应开放补充材料 | 论文 Fetch、补充材料获取与审查 | 来源状态、材料和审查线索 |
| 审查上传表格 | 表格概览、统一数据审查 | 简短状态 + 一份 HTML 报告 |
| 解读论文、设计实验 | 主 Agent；按需使用导出 | 解释或可编辑报告 |
| 保存/回顾课题记录 | 账号内课题记录工具 | 跨会话记录 |
| 绘制流程图 | 开启可视化后使用 SVG 工具 | 安全校验过的可编辑 SVG |

## 能力边界

- 本地检索只查当前部署已安装并建索引的授权语料，不自动下载全网文献。
- 联网结果受网络、来源开放状态、服务商额度和页面结构影响；不绕过付费全文。
- PDF/Word 抽取受文档格式影响；原生文本、扫描件和多栏布局可能出现不同结果。
- 数值审查不是统计审稿或学术不端判定；图像完整性复核不在当前数值审查链路内。
- 当前没有专用柑橘病害分类器或已标注病害图库；图像判断依赖主模型真实视觉能力。
- 模型视觉、上下文、用量及缓存状态以服务商真实 API 回执为准。
