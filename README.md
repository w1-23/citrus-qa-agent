# CitrusQA：面向柑橘研究的可溯源问答系统

CitrusQA 是一个面向柑橘研究的检索增强问答原型，针对“中文提问、英文文献”场景组织检索与回答。系统用提问者的语言作答，并把本地文献证据与联网补充分段呈现，便于读者区分来源并核对引用。

> 本仓库公开系统代码和构建脚本，不包含知识库、完整论文文件、模型权重、私有数据或运行凭据。运行系统需要自行准备有权使用的本地语料，并在本机配置模型服务。

## 系统流程

```text
中文问题
   │ 忠实翻译为英文检索式
   ▼
英文柑橘文献库 ── 词法与稠密双路检索 ── 证据去重、装配与引用校验
                                                     │
联网信息分支 ── 时效信息与独立引用编号 ──────────────┤
                                                     ▼
                本地文献回答 + 明确标注“未经本地验证”的联网补充
```

本地文献与联网来源分别维护证据池和编号空间。联网内容放在独立段落，不进入本地文献引用池；本地引用可按 DOI 回溯。交付前的代码检查用于核对编号、来源池和部分数值对应关系，不能替代对论断语义的人工审读。

## 研究稿件报告的系统快照与检查

以下数据来自当前研究稿件所记录的实验版本，不代表所有配置下的性能保证：

- 英文知识库快照包含 **4,906 份文献、126,494 个文本块**。语料文件不随本仓库发布。
- 在 **144 条三来源回答**中，本地段未出现联网引用编号 `[Wn]` 或预先指定的 URL/域名模式；联网段记录到 820 次 `[Wn]`。这是来源边界的结构与词法检查。
- 在独立的 **84 题系统批次**中，1,649 个本地正文引用标记均能映射到对应证据池，未发现池外编号。
- 架构定型前的混合证据探索实验中，未过滤混入联网内容的条件下，评审模型标记比例为 24.0%（23/96）；本地对照为 3.1%（3/96）。该实验发生在分离式架构实施前，受证据预览等条件限制，不能作为最终系统降低幻觉率的因果证据。

结构检查通过不等同于回答中的每项论断都获得了文献支持，也不能证明联网信息与模型内部信息完全隔离。上述读数只适用于稿件所述样本、流程和检查规则。

## 代码结构

- `01_源码_src/`：API、检索、证据装配、引用校验与智能体实现。
- `02_配置_config/`：系统配置。
- `04_脚本_scripts/`：知识库准备、索引和模型准备工具。
- `06_网页_index/`：本地问答界面。
- `run.ps1`、`stop.ps1`：Windows 本地启动与停止脚本。
- `agent/`：本地运行数据、缓存、状态与日志目录，不应提交到 Git。

## 本地运行

环境要求：Windows PowerShell、Python 3.10–3.12、Git。首次启动还需要联网安装依赖和下载公开模型权重；运行问答服务需要配置可用的模型 API 凭据。凭据只应保存在本机，不要提交到仓库。

```powershell
git clone https://github.com/w1-23/citrus-qa-agent.git
cd citrus-qa-agent
```

把自行准备且有权使用的知识库索引放入 `agent/data/lancedb/`，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

脚本会检查本地索引、准备 Python 环境和依赖、下载所需模型并启动本地服务。浏览器打开 `http://localhost:8000` 后，按部署环境配置模型 API。没有本地索引时，脚本会停止并提示所需目录；本仓库不提供语料下载。
